圖文動態網頁簡報 Skill｜Windows Codex Desktop 學員安裝說明

最簡單安裝：
1. 下載後先在 ZIP 檔上按右鍵 →「內容」→ 勾選「解除封鎖」→「確定」。
   （這一步可以避免 Windows 把安裝檔擋下來；如果內容視窗裡沒有「解除封鎖」選項，直接跳過即可。）
2. 把整個 ZIP 解壓縮，不要直接在 ZIP 裡執行。
3. 雙擊 install-web-ppt-skill.cmd。
   如果跳出藍色「Windows 已保護您的電腦」或「安全性警告」視窗，這是 Windows
   對網路下載檔案的正常提醒，不是中毒：點「其他資訊」→「仍要執行」（或「執行」）即可。
4. 看到 Skill files copied successfully 後關閉視窗。
5. 回到 Codex；若原本已開著，先重新啟動。
6. 在新任務輸入 $build-visual-web-ppt。能選到「圖文動態網頁簡報」才算安裝完成。

使用方式：
在 Codex 新任務輸入 $build-visual-web-ppt，接著貼上或指定你的課程資料。

範例：
請使用 $build-visual-web-ppt，把這個資料夾裡的課程資料做成以 index.html 為入口的圖文動態網頁簡報資料夾。請預設使用繁體中文，依內容選配色，重要概念用動態說明，需要的插圖直接使用繪圖模型製作。

手動安裝備援：
把 build-visual-web-ppt 整個資料夾複製到：
%USERPROFILE%\.codex\skills\build-visual-web-ppt

本安裝包對應本課程使用的 Windows Codex Desktop。不同版本的介面或資料夾位置可能不同，最後一律以 $build-visual-web-ppt 是否能在 Codex 中被選到為準。
